# MakerLoan — Backend (NestJS)

```bash
cp .env.example .env     # set secrets; needs a running MongoDB
npm install
npm run seed             # demo users (password: Password123) + equipment
npm run start:dev        # http://localhost:3000/api  — Swagger: /api/docs
```
